# ⏱️ Complexity Analysis

Every solution should be analyzed in terms of:

- **Time Complexity**
- **Space Complexity**

Complexity analysis helps us understand how an algorithm behaves as the input size increases.

## Common Complexities

| Complexity | Name | Typical Example |
|---|---|---|
| `O(1)` | Constant | Array access |
| `O(log n)` | Logarithmic | Binary Search |
| `O(n)` | Linear | Single loop |
| `O(n log n)` | Linearithmic | Merge Sort |
| `O(n²)` | Quadratic | Nested loops |
| `O(n³)` | Cubic | Three nested loops |
| `O(2ⁿ)` | Exponential | Subset generation |
| `O(n!)` | Factorial | Permutation generation |

## Complexity Preference

Generally, lower complexity is preferred:

```text
O(1)
  ↓
O(log n)
  ↓
O(n)
  ↓
O(n log n)
  ↓
O(n²)
  ↓
O(n³)
  ↓
O(2ⁿ)
  ↓
O(n!)
```
